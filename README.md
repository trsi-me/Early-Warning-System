# نظام الإنذار المبكر

## وصف المشروع

نظام الإنذار المبكر هو تطبيق ويب محلي لإدارة المؤشرات والتنبيهات. يتيح النظام إدخال مؤشرات نصية ورقمية من مصادر مختلفة، مع آلية تلقائية لكشف الشذوذ وإنشاء تنبيهات عند اكتشاف أنماط غير طبيعية في البيانات.

## المميزات الرئيسية

- نظام تسجيل دخول آمن باستخدام Flask sessions
- إدارة شاملة للشركات والمؤسسات مع تتبع المخاطر والاستراتيجيات
- إدارة المؤشرات (نصية ورقمية) مع إمكانية إضافة وصف ومصدر وتاريخ
- آلية كشف شذوذ تلقائية تعمل على قواعد قابلة للتعديل
- نظام تنبيهات متعدد المستويات (عالي، متوسط، منخفض)
- إدارة المخاطر المتقدمة مع تصنيفات متعددة وخطط التخفيف
- تحليلات مالية شاملة مع مؤشرات الأداء الرئيسية (ROE, ROA, نسبة السيولة، إلخ)
- نظام إشعارات محاكي للإخطار الفوري بالمخاطر والتحسينات
- إصدار تقارير متعددة الصيغ (JSON, CSV, TXT)
- لوحة تحكم تعرض إحصائيات شاملة وآخر المؤشرات والتنبيهات
- واجهة مستخدم متجاوبة مع تصميم Dark Mode احترافي
- بيانات افتراضية غنية للاختبار والتدريب

## متطلبات التشغيل

- Python 3.10.6
- نظام تشغيل Windows
- اتصال بالإنترنت (لتحميل مكتبة Chart.js من CDN - اختياري)

## طريقة التشغيل

### 1. إنشاء بيئة افتراضية

افتح PowerShell أو Command Prompt وانتقل إلى مجلد المشروع:

```
cd "C:\Users\TRSI\VSCode\Projects\Early Warning System"
```

أنشئ بيئة افتراضية:

```
python -m venv venv
```

فعّل البيئة الافتراضية:

```
venv\Scripts\activate
```

### 2. تثبيت المكتبات

ثبّت المكتبات المطلوبة:

```
pip install -r requirements.txt
```

### 3. تهيئة قاعدة البيانات

شغّل سكربت تهيئة قاعدة البيانات:

```
python db_init.py
```

سيتم إنشاء قاعدة البيانات في `data/ews.db` مع الجداول الأساسية ومستخدم إداري افتراضي.

**ملاحظة مهمة:** المستخدم الافتراضي هو:
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

**يجب تغيير كلمة المرور بعد التشغيل الاختباري لأسباب أمنية.**

### 4. تشغيل التطبيق

شغّل التطبيق:

```
python app.py
```

سيعمل التطبيق على العنوان: `http://127.0.0.1:5000`

افتح المتصفح وانتقل إلى العنوان أعلاه للبدء في استخدام النظام.

## قواعد كشف الشذوذ

يعمل النظام على ثلاث قواعد رئيسية لكشف الشذوذ:

### القاعدة 1: انحراف كبير في القيمة الرقمية
إذا كان المؤشر رقمي وكانت القيمة تمثل نسبة مئوية للانخفاض أو الارتفاع، وقيمة الانحراف المطلق >= الحد المحدد (افتراضي: 20%)، يتم إنشاء تنبيه بمستوى **عالي**.

**تعديل القاعدة:** قم بتحديث قيمة `anomaly_threshold_percentage` في جدول `settings`.

### القاعدة 2: انحراف عن المتوسط التاريخي
إذا كان المؤشر رقمي وانحراف القيمة عن المتوسط التاريخي للمؤشرات الرقمية أكبر من الحد المحدد (افتراضي: 2.5 انحراف معياري)، يتم إنشاء تنبيه بمستوى **متوسط**.

**تعديل القاعدة:** قم بتحديث قيمة `anomaly_threshold_deviation` في جدول `settings`.

### القاعدة 3: عدد كبير من المؤشرات من نفس المصدر
إذا تم إدخال أكثر من الحد المحدد (افتراضي: 5) من المؤشرات من نفس المصدر خلال 24 ساعة، يتم إنشاء تنبيه بمستوى **متوسط**.

**تعديل القاعدة:** قم بتحديث قيمة `max_indicators_per_source_24h` في جدول `settings`.

### تعديل قواعد كشف الشذوذ

يمكن تعديل القواعد من خلال جدول `settings` في قاعدة البيانات:

1. افتح قاعدة البيانات باستخدام أداة SQLite (مثل DB Browser for SQLite)
2. انتقل إلى جدول `settings`
3. عدّل القيم حسب الحاجة:
   - `anomaly_threshold_percentage`: نسبة الانحراف المئوية للتنبيه العالي
   - `anomaly_threshold_deviation`: عدد الانحرافات المعيارية للتنبيه المتوسط
   - `max_indicators_per_source_24h`: الحد الأقصى لعدد المؤشرات من نفس المصدر
   - `anomaly_check_enabled`: تفعيل/تعطيل كشف الشذوذ (true/false)

## استخدام الواجهة

### تسجيل الدخول
1. افتح المتصفح وانتقل إلى `http://127.0.0.1:5000`
2. أدخل اسم المستخدم وكلمة المرور (admin / admin123)
3. اضغط على "تسجيل الدخول"

### الإشعارات
- تظهر أيقونة الإشعارات في شريط التنقل العلوي
- اضغط على الأيقونة لعرض الإشعارات الجديدة
- يتم تحديث الإشعارات تلقائياً كل 30 ثانية
- يمكنك النقر على الإشعار لتعليمه كمقروء

### لوحة التحكم
تعرض لوحة التحكم:
- إحصائيات التنبيهات حسب المستوى
- آخر 10 مؤشرات تم إدخالها
- آخر 10 تنبيهات
- رسم بياني لتوزيع التنبيهات

### إضافة مؤشر جديد
1. من القائمة العلوية، اضغط على "إضافة مؤشر"
2. املأ الحقول المطلوبة:
   - العنوان (مطلوب)
   - الوصف (اختياري)
   - المصدر (مطلوب)
   - نوع المؤشر: نصي أو رقمي (مطلوب)
   - القيمة حسب النوع المختار
   - التاريخ (مطلوب)
3. اضغط على "حفظ"

سيتم فحص المؤشر تلقائياً وفق قواعد كشف الشذوذ، وإنشاء تنبيهات إذا لزم الأمر.

### عرض المؤشرات
1. من القائمة العلوية، اضغط على "المؤشرات"
2. ستظهر قائمة بجميع المؤشرات مع تفاصيلها

### إدارة التنبيهات
1. من القائمة العلوية، اضغط على "التنبيهات"
2. يمكنك تصفية التنبيهات حسب الحالة (جديد، معترف به، محلول)
3. للتنبيهات الجديدة: اضغط على "اعتراف" للاعتراف بالتنبيه
4. للتنبيهات المعترف بها: اضغط على "حل" لحل التنبيه

### إدارة الشركات
1. من القائمة العلوية، اضغط على "الشركات"
2. ستظهر قائمة بجميع الشركات مع معلوماتها الأساسية
3. اضغط على أي شركة لعرض تفاصيلها الكاملة:
   - الاستراتيجيات المرتبطة
   - المخاطر الحالية
   - التحليلات المالية الأخيرة

### إدارة المخاطر
1. من القائمة العلوية، اضغط على "إدارة المخاطر"
2. يمكنك تصفية المخاطر حسب الشركة أو المستوى
3. عرض إحصائيات شاملة عن المخاطر
4. تحديث حالة المخاطر (نشط، مخفف، محلول)

### إصدار التقارير
1. من القائمة العلوية، اضغط على "التقارير"
2. اختر نوع التقرير (شامل، مخاطر، مالي)
3. اختر صيغة التقرير (JSON, CSV, TXT)
4. اختر الشركة (اختياري) أو اتركه "الكل"
5. اضغط على "إنشاء التقرير"
6. سيتم حفظ التقرير في مجلد `data/reports/`
7. يمكنك تحميل التقارير السابقة من قائمة التقارير

### حول المشروع والسياسات
- اضغط على "حول المشروع" لعرض معلومات عن المشروع والفريق
- اضغط على "السياسات" لعرض شروط الاستخدام وسياسات الخصوصية

## البيانات الافتراضية

عند تشغيل `db_init.py` لأول مرة، سيتم إنشاء:
- 8 شركات في قطاعات مختلفة
- 32 استراتيجية موزعة على الشركات
- 30-50 مخاطرة مع تصنيفات مختلفة
- 96 تحليل مالي (12 لكل شركة)
- 120-200 مؤشر افتراضي
- 30 تنبيه افتراضي
- 4 إشعارات افتراضية

هذه البيانات تساعد في اختبار النظام وفهم كيفية عمله.

## استكشاف الأخطاء

### خطأ في الاتصال بقاعدة البيانات
تأكد من تشغيل `db_init.py` أولاً لإنشاء قاعدة البيانات.

### خطأ في تثبيت المكتبات
تأكد من استخدام Python 3.10.6 وتفعيل البيئة الافتراضية قبل التثبيت.

### الخطوط لا تظهر بشكل صحيح
تأكد من وجود ملفات الخطوط في `static/assets/fonts/` وأن المسار في CSS صحيح.

### التطبيق لا يعمل على المنفذ 5000
يمكنك تغيير المنفذ في ملف `app.py` في السطر الأخير.
