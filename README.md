# نظام الإنذار المبكر - دليل شامل للمبتدئين

## ما هو نظام الإنذار المبكر؟

نظام الإنذار المبكر (Early Warning System) هو تطبيق ويب يساعد المؤسسات والشركات على مراقبة المؤشرات المهمة واكتشاف المشاكل قبل أن تتفاقم. تخيل أنك تدير شركة وتريد أن تعرف فوراً إذا انخفضت المبيعات بشكل كبير، أو إذا ظهرت مشكلة في الإنتاج، أو إذا حدث شيء غير طبيعي في البيانات المالية. هذا النظام يقوم بذلك تلقائياً.

### مثال واقعي:
- **شركة تصنيع**: تراقب معدل الإنتاج اليومي. إذا انخفض الإنتاج بنسبة 25% عن المتوسط، يرسل النظام تنبيهاً فورياً للمدير.
- **مؤسسة مالية**: تراقب نسبة السيولة. إذا تجاوزت نسبة الدين حداً معيناً، يتم إنشاء تنبيه عالي المستوى.
- **مستشفى**: تراقب عدد الحالات الحرجة. إذا زاد العدد بشكل غير طبيعي، يتم التنبيه فوراً.

## كيف يعمل النظام؟

### 1. إدخال البيانات (Input)
المستخدم يدخل مؤشرات من مصادر مختلفة:
- **مؤشرات رقمية**: مثل نسبة المبيعات (85%)، عدد الموظفين (150)، نسبة الربح (12.5%)
- **مؤشرات نصية**: مثل "تأخير في تسليم الطلبات"، "مشكلة في خط الإنتاج رقم 3"

### 2. التحليل التلقائي (Analysis)
النظام يفحص كل مؤشر جديد تلقائياً باستخدام ثلاث قواعد:

#### القاعدة الأولى: الانحراف الكبير
- **كيف تعمل**: تقارن القيمة الجديدة بالقيم السابقة
- **مثال**: إذا كان متوسط المبيعات الشهرية 100,000 ريال، والمبيعات هذا الشهر 70,000 ريال (انخفاض 30%)
- **النتيجة**: تنبيه عالي المستوى

#### القاعدة الثانية: الانحراف الإحصائي
- **كيف تعمل**: تستخدم الإحصاء (الانحراف المعياري) لاكتشاف القيم الشاذة
- **مثال**: إذا كان متوسط نسبة الربح 10% مع انحراف معياري 2%، وقيمة جديدة 18% (أكثر من 2.5 انحراف معياري)
- **النتيجة**: تنبيه متوسط المستوى

#### القاعدة الثالثة: كثرة المؤشرات من مصدر واحد
- **كيف تعمل**: تراقب عدد المؤشرات من نفس المصدر خلال 24 ساعة
- **مثال**: إذا أرسل قسم المبيعات أكثر من 5 مؤشرات خلال يوم واحد
- **النتيجة**: تنبيه متوسط المستوى (قد يشير إلى مشكلة في القسم)

### 3. إنشاء التنبيهات (Alerts)
عند اكتشاف شذوذ، ينشئ النظام تنبيهاً بمستوى مناسب:
- **عالي (High)**: مشاكل خطيرة تحتاج تدخل فوري
- **متوسط (Medium)**: مشاكل تحتاج مراقبة
- **منخفض (Low)**: ملاحظات مهمة

### 4. الإشعارات (Notifications)
يتم إرسال إشعار فوري للمستخدمين المعنيين في لوحة التحكم.

### 5. التقارير (Reports)
يمكن إنشاء تقارير بصيغ مختلفة (JSON, CSV, TXT) لتحليل البيانات.

## التقنيات المستخدمة وشرحها

### 1. Python
**ما هو؟** لغة برمجة قوية وسهلة التعلم، تستخدم في تطوير الويب، تحليل البيانات، والذكاء الاصطناعي.

**لماذا استُخدمت هنا؟** 
- سهولة التعامل مع قواعد البيانات
- مكتبات جاهزة للتحليل الإحصائي
- مناسبة للمبتدئين

**مثال واقعي**: مثل استخدام اللغة العربية للكتابة - Python هي اللغة التي نكتب بها التعليمات للحاسوب.

### 2. Flask
**ما هو؟** إطار عمل (Framework) مبني على Python لإنشاء تطبيقات الويب بسرعة.

**كيف يعمل؟**
- عندما تفتح صفحة في المتصفح (مثل `http://127.0.0.1:5000/dashboard`)
- Flask يستقبل الطلب ويحدد أي صفحة تريد
- يجلب البيانات من قاعدة البيانات
- يرسل الصفحة المطلوبة للمتصفح

**مثال واقعي**: مثل مطعم - العميل يطلب طبقاً (URL)، النادل (Flask) يأخذ الطلب للمطبخ (قاعدة البيانات)، ثم يقدم الطبق (الصفحة).

**مثال في الكود**:
```python
@app.route('/dashboard')  # العنوان في المتصفح
def dashboard():          # الدالة التي تنفذ عند زيارة العنوان
    return render_template('dashboard.html')  # إرسال الصفحة
```

### 3. SQLite
**ما هو؟** قاعدة بيانات خفيفة وسهلة، تخزن البيانات في ملف واحد على جهازك.

**كيف تعمل؟**
- البيانات تُخزن في جداول (Tables) مثل Excel
- كل جدول له أعمدة (Columns) وصفوف (Rows)
- يمكن البحث والتعديل باستخدام لغة SQL

**مثال واقعي**: مثل دفتر ملاحظات منظم:
- **جدول المستخدمين**: اسم المستخدم | كلمة المرور المشفرة | تاريخ التسجيل
- **جدول المؤشرات**: العنوان | القيمة | التاريخ | المصدر
- **جدول التنبيهات**: المستوى | الرسالة | الحالة | التاريخ

**مثال في الكود**:
```python
# إنشاء جدول
cursor.execute('''
CREATE TABLE indicators (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    numeric_value REAL
)
''')

# إدخال بيانات
cursor.execute('INSERT INTO indicators (title, numeric_value) VALUES (?, ?)', 
               ('نسبة المبيعات', 85.5))
```

### 4. HTML/CSS/JavaScript
**ما هي؟** لغات بناء صفحات الويب:

- **JavaScript**: التفاعل (النقر على الأزرار، تحديث البيانات تلقائياً)

**مثال واقعي**: 
- **HTML**: مثل هيكل البيت (الجدران، الأبواب، النوافذ)
- **CSS**: مثل الديكور والألوان
- **JavaScript**: مثل الكهرباء التي تجعل الأضواء تعمل

### 5. Werkzeug Security
**ما هو؟** مكتبة Python لتشفير كلمات المرور.

**كيف يعمل؟**
- لا تُخزن كلمات المرور كما هي (هذا خطر أمني)
- يتم تحويلها إلى "hash" (نص مشفر لا يمكن عكسه)
- عند تسجيل الدخول، يتم تشفير كلمة المرور المدخلة ومقارنتها بالمشفرة المخزنة

**مثال واقعي**: مثل قفل آمن - لا يمكنك رؤية المفتاح الأصلي، لكن يمكنك التحقق من أن المفتاح الذي لديك صحيح.

**مثال في الكود**:
```python
# تشفير كلمة المرور
password_hash = generate_password_hash('admin123')
# النتيجة: 'pbkdf2:sha256:260000$...' (نص طويل مشفر)

# التحقق من كلمة المرور
if check_password_hash(stored_hash, 'admin123'):
    print('كلمة المرور صحيحة')
```

### 6. Chart.js
**ما هو؟** مكتبة JavaScript لرسم الرسوم البيانية.

**كيف يعمل؟**
- تأخذ البيانات من قاعدة البيانات
- ترسمها كرسم بياني (دائري، عمودي، خطي)
- يتم تحديثها تلقائياً عند تغيير البيانات

**مثال واقعي**: مثل رسم بياني في Excel، لكن تفاعلي ويحدث تلقائياً.

## شرح قواعد كشف الشذوذ بالتفصيل

### القاعدة 1: الانحراف المئوي الكبير

**كيف تعمل:**
1. النظام يحسب نسبة التغيير بين القيمة الجديدة والقيمة السابقة
2. إذا كانت النسبة أكبر من الحد المحدد (افتراضي: 20%)، ينشئ تنبيهاً عالي المستوى

**مثال تفصيلي:**
```
القيمة السابقة: 100,000 ريال (مبيعات الشهر الماضي)
القيمة الجديدة: 70,000 ريال (مبيعات هذا الشهر)
الانحراف: (100,000 - 70,000) / 100,000 = 30%
النتيجة: 30% > 20% → تنبيه عالي!
```

**مثال واقعي:**
- شركة كانت تبيع 1000 منتج شهرياً
- هذا الشهر باعت 700 منتج فقط
- النظام يكتشف الانخفاض (30%) وينشئ تنبيهاً فورياً

**كيف تعدل القاعدة:**
افتح قاعدة البيانات وعدّل قيمة `anomaly_threshold_percentage` في جدول `settings`:
- قيمة أقل (مثل 10%) = أكثر حساسية (تنبيهات أكثر)
- قيمة أعلى (مثل 30%) = أقل حساسية (تنبيهات أقل)

### القاعدة 2: الانحراف الإحصائي

**كيف تعمل:**
1. النظام يحسب المتوسط والانحراف المعياري لجميع القيم السابقة
2. إذا كانت القيمة الجديدة خارج نطاق (المتوسط ± 2.5 × الانحراف المعياري)، ينشئ تنبيهاً متوسط المستوى

**شرح الإحصاء المبسط:**
- **المتوسط (Mean)**: مجموع القيم مقسوم على عددها
- **الانحراف المعياري (Standard Deviation)**: مقياس لمدى تشتت القيم عن المتوسط

**مثال تفصيلي:**
```
القيم السابقة: [10, 11, 9, 10, 12, 10, 11, 9, 10, 11]
المتوسط: 10.3
الانحراف المعياري: 0.95
القيمة الجديدة: 15

الحد الأعلى: 10.3 + (2.5 × 0.95) = 12.675
الحد الأدنى: 10.3 - (2.5 × 0.95) = 7.925

15 > 12.675 → خارج النطاق الطبيعي → تنبيه متوسط!
```

**مثال واقعي:**
- متوسط نسبة الربح الشهرية: 10% مع تقلبات طبيعية ±2%
- هذا الشهر: نسبة الربح 18%
- النظام يكتشف أن هذه قيمة شاذة إحصائياً (خارج النطاق الطبيعي)

**كيف تعدل القاعدة:**
عدّل قيمة `anomaly_threshold_deviation` في جدول `settings`:
- قيمة أقل (مثل 2.0) = أكثر حساسية
- قيمة أعلى (مثل 3.0) = أقل حساسية

### القاعدة 3: كثرة المؤشرات من مصدر واحد

**كيف تعمل:**
1. النظام يعد المؤشرات من كل مصدر خلال آخر 24 ساعة
2. إذا تجاوز العدد الحد المحدد (افتراضي: 5)، ينشئ تنبيهاً متوسط المستوى

**مثال تفصيلي:**
```
المصدر: "قسم المبيعات"
المؤشرات خلال 24 ساعة:
- 10:00 صباحاً: مؤشر 1
- 11:30 صباحاً: مؤشر 2
- 1:00 ظهراً: مؤشر 3
- 3:00 عصراً: مؤشر 4
- 4:30 عصراً: مؤشر 5
- 5:00 عصراً: مؤشر 6

العدد: 6 > 5 → تنبيه متوسط!
```

**مثال واقعي:**
- قسم المبيعات عادة يرسل 1-2 مؤشر يومياً
- اليوم أرسل 7 مؤشرات خلال ساعات قليلة
- النظام يشك أن هناك مشكلة في القسم (ضغط عمل، مشاكل متعددة، أو خطأ في النظام)

**كيف تعدل القاعدة:**

## شرح المؤشرات المالية (للمبتدئين)

### ROE (Return on Equity) - العائد على حقوق الملكية

**ما هو؟** نسبة تُظهر مدى كفاءة الشركة في استخدام أموال المساهمين لتحقيق ربح.

**الصيغة:** الربح الصافي ÷ حقوق الملكية × 100

**مثال:**
- حقوق الملكية: 1,000,000 ريال
- الربح الصافي: 150,000 ريال
- ROE = 150,000 ÷ 1,000,000 × 100 = 15%

**التفسير:**
- ROE عالي (مثل 20%+) = الشركة تستخدم أموال المساهمين بكفاءة عالية
- ROE منخفض (مثل 5%-) = الشركة لا تحقق عائد جيد على استثمار المساهمين

**مثال واقعي:**
شركة استثمر فيها المساهمون 10 مليون ريال، وتحقق ربح 1.5 مليون سنوياً. ROE = 15%، وهذا جيد.

### ROA (Return on Assets) - العائد على الأصول

**ما هو؟** نسبة تُظهر مدى كفاءة الشركة في استخدام أصولها لتحقيق ربح.

**الصيغة:** الربح الصافي ÷ إجمالي الأصول × 100

**مثال:**
- إجمالي الأصول: 2,000,000 ريال
- الربح الصافي: 160,000 ريال
- ROA = 160,000 ÷ 2,000,000 × 100 = 8%

**التفسير:**
- ROA عالي = الشركة تستخدم أصولها بكفاءة
- ROA منخفض = الأصول لا تولد ربحاً كافياً

**مثال واقعي:**
شركة لديها مصانع ومعدات بقيمة 20 مليون ريال، وتحقق ربح 1.6 مليون. ROA = 8%، وهذا معقول.

### نسبة السيولة (Liquidity Ratio)

**ما هو؟** نسبة تُظهر قدرة الشركة على سداد ديونها قصيرة الأجل.

**الصيغة:** الأصول المتداولة ÷ الخصوم المتداولة

**مثال:**
- الأصول المتداولة (نقد، مخزون، ذمم): 500,000 ريال
- الخصوم المتداولة (ديون قصيرة الأجل): 300,000 ريال
- نسبة السيولة = 500,000 ÷ 300,000 = 1.67

**التفسير:**
- نسبة > 1 = الشركة تستطيع سداد ديونها (جيد)
- نسبة < 1 = الشركة قد تواجه مشاكل في السداد (سيء)
- نسبة 1.5-2.5 = مثالية

**مثال واقعي:**
شركة لديها 500 ألف نقد ومخزون، وديون 300 ألف مستحقة خلال سنة. النسبة 1.67 تعني أنها قادرة على السداد.

### النسبة الحالية (Current Ratio)

**ما هو؟** نفس نسبة السيولة (أسماء مختلفة لنفس المفهوم).

### النسبة السريعة (Quick Ratio)

**ما هو؟** مثل النسبة الحالية، لكن تستبعد المخزون (لأن تحويل المخزون لنقد قد يستغرق وقتاً).

**الصيغة:** (الأصول المتداولة - المخزون) ÷ الخصوم المتداولة

**مثال:**
- الأصول المتداولة: 500,000 ريال
- المخزون: 200,000 ريال
- الخصوم المتداولة: 300,000 ريال
- النسبة السريعة = (500,000 - 200,000) ÷ 300,000 = 1.0

**التفسير:**
- نسبة > 1 = جيد (حتى بدون بيع المخزون، تستطيع السداد)
- نسبة < 1 = قد تحتاج لبيع المخزون لسداد الديون

### نسبة الدين (Debt Ratio)

**ما هو؟** نسبة تُظهر مدى اعتماد الشركة على الديون مقابل الأموال الخاصة.

**الصيغة:** إجمالي الديون ÷ إجمالي الأصول × 100

**مثال:**
- إجمالي الديون: 900,000 ريال
- إجمالي الأصول: 2,000,000 ريال
- نسبة الدين = 900,000 ÷ 2,000,000 × 100 = 45%

**التفسير:**
- نسبة < 30% = قليل الاعتماد على الديون (آمن)
- نسبة 30-60% = معقول
- نسبة > 60% = اعتماد عالي على الديون (خطر)

**مثال واقعي:**
شركة أصولها 2 مليون، منها 900 ألف ديون. نسبة الدين 45% تعني أن 45% من الأصول ممولة بالديون، و55% بأموال المساهمين.

```python
# في نهاية الملف، غيّر:
app.run(debug=True, port=5001)  # بدلاً من 5000
```


**شرح:** CSS يحتاج لمسار صحيح للوصول لملفات الخطوط.

### المشكلة 5: التطبيق بطيء أو يتجمد

**السبب المحتمل:** قاعدة البيانات كبيرة جداً أو استعلامات غير محسّنة.

**الحل:**

3. أعد تشغيل `db_init.py` لإنشاء قاعدة بيانات جديدة (سيتم حذف البيانات القديمة!)

**تحذير:** إعادة تشغيل `db_init.py` ستحذف جميع البيانات!

## مصطلحات تقنية مبسطة

### API (Application Programming Interface)
**ما هو؟** واجهة تسمح لبرنامجين بالتواصل مع بعضهما.

**مثال واقعي:** مثل قائمة طعام في مطعم - القائمة (API) تخبرك ما يمكن طلبه، لكن لا تخبرك كيف يُعد الطعام (الكود الداخلي).

**في هذا المشروع:** عندما تفتح لوحة التحكم، JavaScript يرسل طلب API للخادم لجلب البيانات.

### AJAX (Asynchronous JavaScript and XML)
**ما هو؟** تقنية تسمح بتحديث الصفحة دون إعادة تحميلها كاملة.

**مثال واقعي:** مثل تحديث حالة الطقس في تطبيق الهاتف - البيانات تتحدث، لكن التطبيق لا يعيد فتحه.

**في هذا المشروع:** الإشعارات تتحدث كل 30 ثانية دون إعادة تحميل الصفحة.

### Session (الجلسة)
**ما هو؟** طريقة لحفظ حالة المستخدم (مثل: هل هو مسجل دخول؟) بين طلبات الصفحات المختلفة.

**مثال واقعي:** مثل بطاقة دخول للمكتب - تثبت أنك موظف مسموح له بالدخول.

**في هذا المشروع:** بعد تسجيل الدخول، Flask يحفظ session في المتصفح. عند زيارة صفحة محمية، يتحقق من Session أولاً.

### Hash (التشفير)
**ما هو؟** عملية تحويل نص إلى نص آخر مشفر لا يمكن عكسه.

**مثال واقعي:** مثل تحويل وصفة طعام إلى رقم سري - يمكنك التحقق من أن الوصفة صحيحة، لكن لا يمكنك معرفة الوصفة الأصلية من الرقم.

**في هذا المشروع:** كلمات المرور تُحول إلى hash قبل الحفظ في قاعدة البيانات.

### SQL (Structured Query Language)
**ما هو؟** لغة للتعامل مع قواعد البيانات (البحث، الإضافة، التعديل، الحذف).

**مثال بسيط:**
```sql
-- جلب جميع المستخدمين
SELECT * FROM users;

-- إضافة مستخدم جديد
INSERT INTO users (username, password_hash) VALUES ('ahmed', 'hash123');

-- تحديث بيانات
UPDATE users SET username = 'ahmed_new' WHERE id = 1;

-- حذف مستخدم
DELETE FROM users WHERE id = 1;
```

**في هذا المشروع:** جميع العمليات على قاعدة البيانات تستخدم SQL.

### JSON (JavaScript Object Notation)
**ما هو؟** صيغة لتنظيم البيانات بشكل قابل للقراءة.

**مثال:**
```json
{
    "name": "شركة التصنيع",
    "revenue": 1000000,
    "risk_level": "medium",
    "indicators": [1, 2, 3]
}
```

**في هذا المشروع:** البيانات تُرسل بين الخادم والمتصفح بصيغة JSON.

### CDN (Content Delivery Network)
**ما هو؟** شبكة من الخوادم حول العالم لتوزيع الملفات بسرعة.

**مثال واقعي:** مثل وجود نسخ من كتاب في مكتبات مختلفة - أقرب مكتبة لك تقدم الكتاب بسرعة.

**في هذا المشروع:** Chart.js يُحمّل من CDN بدلاً من تثبيته محلياً (أسرع وأسهل).

## أمثلة واقعية لاستخدام النظام

### مثال 1: شركة تصنيع

**السيناريو:**
شركة تصنيع تراقب معدل الإنتاج اليومي. المعدل الطبيعي: 1000 وحدة/يوم.

**استخدام النظام:**
1. كل يوم، مدير الإنتاج يدخل مؤشر رقمي: عدد الوحدات المنتجة
2. النظام يحسب المتوسط والانحراف المعياري
3. في يوم معين، الإنتاج: 700 وحدة فقط
4. النظام يكتشف الانخفاض (30%) وينشئ تنبيه عالي
5. المدير يتلقى إشعار فوري
6. يتحقق من المشكلة (عطل في الآلة، نقص مواد خام، إلخ)
7. يحل المشكلة ويضع خطة لمنع تكرارها

### مثال 2: مؤسسة مالية

**السيناريو:**
بنك يراقب نسبة السيولة. النسبة المثالية: 1.5-2.0.

**استخدام النظام:**
1. كل شهر، قسم المالية يدخل تحليل مالي جديد
2. النظام يحسب نسبة السيولة تلقائياً
3. في شهر معين، النسبة: 0.9 (أقل من 1!)
4. النظام ينشئ تنبيه عالي (مشكلة خطيرة - قد لا يستطيع البنك سداد التزاماته)
5. الإدارة العليا تتلقى إشعار فوري
6. يتم اتخاذ إجراءات طارئة (بيع أصول، طلب قرض قصير الأجل)

### مثال 3: مستشفى

**السيناريو:**
مستشفى تراقب عدد الحالات الحرجة في قسم الطوارئ. المعدل الطبيعي: 5-10 حالات/يوم.

**استخدام النظام:**
1. كل ساعة، ممرضة تدخل مؤشر: عدد الحالات الحرجة الحالية
2. النظام يراقب الأنماط
3. في يوم معين، خلال 6 ساعات، تم إدخال 8 مؤشرات من "قسم الطوارئ"
4. النظام ينشئ تنبيه متوسط (كثرة المؤشرات من مصدر واحد)
5. مدير المستشفى يتحقق: اكتشف أن هناك حادث كبير تسبب في تدفق الحالات
6. يتم تفعيل خطة الطوارئ (استدعاء أطباء إضافيين، تحضير غرف إضافية)

### مثال 4: شركة تجارية

**السيناريو:**
شركة تجارية تراقب نسبة المبيعات الشهرية. المتوسط: 15% نمو شهري.

**استخدام النظام:**
1. كل شهر، قسم المبيعات يدخل مؤشر: نسبة المبيعات
2. النظام يحسب المتوسط التاريخي والانحراف المعياري
3. في شهر معين، النسبة: 25% (ارتفاع كبير)
4. النظام يكتشف أن هذه قيمة شاذة إحصائياً (خارج النطاق الطبيعي)
5. ينشئ تنبيه متوسط (قد يكون إيجابياً - نمو غير متوقع، أو خطأ في البيانات)
6. المدير يتحقق: اكتشف أن هناك عرض ترويجي كبير سبب النمو
7. يتم توثيق السبب في النظام

## نصائح للمبتدئين

### 1. ابدأ بفهم الأساسيات
قبل تعديل الكود، تأكد من فهم:
- كيف يعمل Flask (المسارات، القوالب)
- كيف تعمل قواعد البيانات (الجداول، الاستعلامات)
- كيف يعمل JavaScript (AJAX، DOM)

### 2. استخدم البيانات التجريبية
النظام يأتي ببيانات تجريبية غنية. استخدمها لفهم كيفية عمل النظام قبل إضافة بيانات حقيقية.

### 3. جرب تعديل القواعد
عدّل قواعد كشف الشذوذ في جدول `settings` وشاهد كيف يتغير سلوك النظام:
- قيم أقل = أكثر حساسية (تنبيهات أكثر)
- قيم أعلى = أقل حساسية (تنبيهات أقل)

### 4. راقب سجل التدقيق (Audit Log)
جدول `audit_log` يسجل جميع العمليات. استخدمه لفهم ما يحدث في النظام.

### 5. اقرأ الأخطاء بعناية
عند حدوث خطأ، اقرأ رسالة الخطأ كاملة. غالباً ما تخبرك بالضبط ما المشكلة وأين.

### 6. استخدم أدوات المطور في المتصفح
اضغط F12 في المتصفح لفتح أدوات المطور:
- **Console**: لرؤية أخطاء JavaScript
- **Network**: لرؤية طلبات AJAX
- **Elements**: لفحص HTML/CSS

### 7. ابدأ بتعديلات بسيطة
لا تحاول تعديل كل شيء دفعة واحدة. ابدأ بتعديلات بسيطة:
- تغيير الألوان في CSS
- إضافة حقل جديد في نموذج
- تعديل رسالة تنبيه

### 8. احتفظ بنسخة احتياطية
قبل إجراء تعديلات كبيرة، احتفظ بنسخة احتياطية من:
- ملف `app.py`
- ملف `data/ews.db`

نظام الإنذار المبكر هو أداة قوية لمراقبة المؤشرات المهمة واكتشاف المشاكل قبل أن تتفاقم. يستخدم تقنيات حديثة لكنها سهلة الفهم:
